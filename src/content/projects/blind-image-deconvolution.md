## Overview

As a Research Fellow in the Computer Vision Lab at Bates College, I worked on image deblurring algorithms aimed at improving point spread function (PSF) estimation, the core problem in recovering a sharp image from a blurred one when the blur itself is unknown ("blind" deconvolution).

## What I built

Extended the lab's existing 2D blind deconvolution pipeline to estimate 3-dimensional kernels for volumetric data, which meant learning MATLAB from scratch to integrate with the existing research codebase and implementing 3D convolution operations end-to-end.
